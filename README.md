Bienvenue sur le dépôt de mon portfolio professionnel, conçu pour présenter mon parcours, mes compétences et mes projets.

--- 

## Stack technique

- **Frontend :** React, Tailwind CSS
- **Backend :** Node.js, Express
- **Base de données :** PostgreSQL
- **Outils :** Git, GitHub, VSC

## Fonctionnalités

Le portfolio comprendra :
- Une présentation de mon parcours et de mes compétences
- Une sélection de mes projets et expériences
- Un CV téléchargeable
- Un formulaire de contact
- Un espace d'administration sécurisé pour gérer les contenus
